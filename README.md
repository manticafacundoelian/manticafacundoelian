#### 🏪 [Technoshop | Análisis de Negocio End-to-End](https://github.com)
Desarrollo completo de una solución analítica para diagnosticar la caída del **-57.11% en la Ganancia Neta** de un retail tecnológico.
* **Ingeniería de Datos:** Construcción de un *pipeline* ETL modular en Python (Pandas) con un infográfico de estructura claro, auditoría automática de calidad de datos (JSON logs) y desnormalización de hechos en `transform.py`.

* **Impacto de Negocio:** Formulación de recomendaciones estratégicas basadas en datos (monto mínimo de compra, renegociación de contratos core y blindaje de clientes de alto valor).
